# ImageTools

Repositorio de herramientas de edición de imágenes desarrolladas para uso personal y para complementar mi portafolio profesional. Este proyecto se centra en la privacidad, el rendimiento y la implementación de soluciones frontend modernas sin dependencias backend.

## Stack Tecnológico

Desarrollado con una arquitectura SPA ligera y eficiente:

*   **Core**: React 18 + Vite
*   **Lenguajes**: JavaScript (ES6+), HTML5 Semántico
*   **Estilos**: CSS3 Nativo (Modular y Responsive)
*   **Workers**: Web Workers para procesamiento de imágenes en segundo plano

## Herramientas Disponibles

### Remove Background
Eliminación automática de fondos utilizando IA en el navegador.

### Resize Image
Redimensionamiento de imágenes con control de calidad y bloqueo de relación de aspecto.

### Crop Image
Recorte de imágenes con previsualización en tiempo real y dimensiones personalizadas.

### Enhance Image
Ajustes de imagen (nitidez, contraste, brillo, saturación) procesados localmente mediante Canvas API.

## Ejecución Local

Para clonar y probar estas herramientas localmente:

```bash
# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Generar build de producción
npm run build
```
